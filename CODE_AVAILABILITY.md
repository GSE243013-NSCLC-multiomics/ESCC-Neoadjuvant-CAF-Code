# Code Availability

The analysis code used to generate the reported results is organized in this
repository together with selected derived tables, figures, metadata/provenance
records, and the R environment lockfile. Large raw datasets and intermediate
analysis objects are not redistributed. The manuscript-associated version of
the repository will be archived in a persistent repository and assigned a DOI
before final publication.
